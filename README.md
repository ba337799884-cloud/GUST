# BatWeb

BatWeb is a simple, responsive homepage for search, useful links, and browser-game sites.

## Features

- Google web search from the main search bar
- Quick links to Gmail, YouTube, Google Maps, and Google Drive
- A game zone with links to browser-game websites
- Responsive layout for phones, tablets, and computers
- No account passwords are collected or stored by BatWeb

## Run locally

Open `index.html` in a modern web browser.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site. The Pages section will show its live URL.

## Google and Gmail

The Gmail link opens Google's official sign-in page. BatWeb does not ask for or store your Google password. A full Google OAuth sign-in feature would require a Google Cloud OAuth client ID and an authorized website domain.

## Note

BatWeb is a normal homepage. It does not proxy websites or bypass school, workplace, or network restrictions. Whether an external website is available depends on the network and that website.
